# ARMORY OS // 3D Interactive Tactical Telemetry & Classification System

Live site: [https://armory.raul.my](https://armory.raul.my)

Military-grade 4K firearm classification, technical telemetry, and 10x exploded CAD schematic visualizer built with Three.js WebGL and Tailwind CSS.

## Features
- **3D Interactive Weapon Schematics**: Procedural PBR models for M4A1, Glock 19, AX338, Benelli M4, Barrett M82A1, Steyr AUG, SCAR 17H, and MP5A3.
- **10x Exploded Disassembly**: 42+ individual components separating along true disassembly vectors with dynamic CAD leader lines.
- **Cyber-Wire X-Ray Diagnostics**: Dual-layer volumetric wireframe with 55,000 PSI chamber stress heatmapping and bore axis laser vector alignment.
- **Component Raycast Inspection**: Hover telemetry revealing NATO nomenclature, alloy specifications (Carpenter 158, 7075-T6, 4140 Steel), and mechanical tolerances.
- **24-Firearm Armorer Database**: Categorized across 8 weapon families with dual layperson vs. armorer visual identification rules.
- **Live Ballistic Comparator**: Head-to-head metric delta analysis across muzzle energy, velocity, and effective range.
- **4K Master Blueprint Suite**: Ultra-high-resolution technical wall posters and CAD disassembly diagrams.
