# ARMORY OS // 3D Interactive Tactical Telemetry & Sensory Architecture

Live production: [https://armory.raul.my](https://armory.raul.my)  
Vercel mirror: [https://armory-os.vercel.app](https://armory-os.vercel.app)

Military-grade 4K firearm classification, technical telemetry, procedural Web Audio soundscapes, and exploded 3D CAD schematic visualizer built with Three.js WebGL and Tailwind CSS.

---

## Phase Two Architecture & Features

### 1. Minimalist 3D Motion Graphic Entrance Portal
- **Holographic Kinetic Breach Core**: Centered gyroscopic CAD wireframe rings with rotating locking lugs, fluted chamber core, glowing bore laser, and drifting ambient 3D star-dust particles.
- **Cinematic Hyperspace Transition**: User click engages the Web Audio API context immediately, triggering a sub-bass chamber warp soundscape and accelerating camera zoom through the core directly into the full armory workspace.
- **Minimalist Mode**: Quick-access `PORTAL` toggle in the top HUD lets users return to the focused, zen 3D kinetic portal anytime.

### 2. Procedural Web Audio Synthesizer (`ArmoryAudio`)
- **Zero External Audio Dependencies**: 100% synthesized in real time via the Web Audio API using dynamic gain envelopes, bandpass resonant filters, and transient harmonic oscillators.
- **Action-Accurate Mechanical Signatures**:
  - *Assault Rifles & Carbines (M4A1, AK-47, SCAR-17H)*: Charging handle pull, bolt carrier friction, 7-lug battery rotation, and buffer spring resonance.
  - *Submachine Guns (HK MP5)*: Authentic cocking handle lock and iconic downward "HK slap" roller-delayed chamber lockup.
  - *Pump-Action Shotguns (Remington 870)*: Dual-direction slide-back ejection stroke and heavy forward breech slam.
  - *Precision Bolt-Action (AIAX .338, CheyTac M200)*: 4-phase turn-bolt operation (60° lift, rearward draw, cartridge chambering push, and solid downward lock).
  - *Striker & Hammer Handguns (Glock 19, 1911)*: Snappy slide rack, short crisp trigger reset tick, and firing pin strike.
  - *Revolvers (Colt Python)*: Multi-stage pawl ratchet cylinder rotation and heavy hammer cock detent.
- **Audio Personalization Modes**:
  - *Tactile Mechanical*: Hyper-realistic steel, titanium, and polymer friction.
  - *Cyber HUD*: High-resonance electronic telemetry tones.
  - *Subdued / Soft*: Attenuated, gentle low-pass clicks tuned for auditory hypersensitivity.

### 3. Tactile Neurodivergent UI & Sensory Ergonomics
- **Multisensory Audio-Haptic Coupling**: Real-time vibration micro-pulses (`navigator.vibrate`) paired synchronously with tactile mechanical clicks.
- **Interactive Tactile Action Lab**:
  - `[ CYCLE ACTION ]` (`Key C`): Physically cycles the 3D bolt carrier / slide / pump / hammer with synchronized mechanical audio.
  - `[ DRY FIRE ]` (`Spacebar`): Crisp trigger break, striker drop against empty breech, and automatic tactile trigger reset.
  - `[ RELOAD MAG ]` (`Key R`): Magazine drops down out of the 3D magwell and snaps back up with a firm palm slap sound and catch latch.
  - `[ EJECT BRASS ]` (`Key E`): Spawns physical 3D brass casings that tumble through the air, hit the floor grid, and bounce with procedural brass ringing acoustics.
- **Stepped Detent Feedback**: Dragging the Exploded View slider triggers tactile notch clicks and haptic micro-pulses every 4%, mimicking a high-end aerospace rotary encoder.
- **Raycast Hover Ticks**: Hovering over any part in the 3D CAD engine produces an ultra-subtle 2,100Hz micro-pip and haptic response.

### 4. Interactive 3D Comparator Engine
- Dual synchronized WebGL viewports comparing any 2 of the 24 firearms side-by-side.
- Linked orbital rotation toggle, 1:1 true physical millimeter scale comparison, raycast telemetry inspection, and live ballistic metric bars.

### 5. Keyboard Shortcuts
- `C`: Cycle action / rack slide
- `Space`: Dry fire trigger pull
- `R`: Reload / drop & seat magazine
- `E`: Eject 3D spent brass casing
- `X`: Toggle exploded view disassembly
- `M`: Toggle audio SFX mute
- `P`: Re-enter 3D motion graphic portal
